5. Enqueue `ExtractReceiptJob` via `IBackgroundJobClient.Enqueue(...)` with `(tenantId, receiptId)` — AFTER `SaveChangesAsync` commits (mirror the enqueue-after-commit pattern used by the finalize→PDF/e-invoice hooks). Do the archive + receipt insert in one `SaveChanges`.

  <action>
Create the Hangfire job mirroring `SendDocumentEmailJob` EXACTLY for the scope + tenant pattern: `RunAsync(Guid tenantId, Guid receiptId, CancellationToken ct)` — `using var scope = _scopeFactory.CreateScope(); scope.ServiceProvider.GetRequiredService<ICurrentTenant>().SetTenant(tenantId);` so RLS applies inside the job. Then:
1. Load the tracked `Receipt` (RLS-scoped); if missing or not `Captured`, log + return (idempotent — never re-extract a Reviewed/Booked receipt).
2. Load the archived original bytes from `receipt_archive` (via `ArchiveId`).
3. Call `IReceiptExtractor.ExtractAsync(bytes, contentType, ct)`. Map the `ReceiptExtraction` fields onto the Receipt (`SupplierName`, `SupplierVatId`, `InvoiceNumber`, `InvoiceDate`, `NetAmount`, `VatAmount`, `GrossAmount`, `VatRatePercent`, `Currency`) — amounts as `decimal`. Serialize the per-field confidences into `Receipt.FieldConfidence` (jsonb).
4. Run `SupplierMatcher.MatchSellerAsync` on the extracted VAT id/name → set `MatchedPartnerId` (provenance only; do NOT auto-create a supplier).
5. Flip `Status = Extracted`, SaveChanges. Do NOT book (hard rule). `[AutomaticRetry(Attempts = 3)]` for transient OCR faults.
With the stub extractor this leaves fields empty (manual entry) — correct default behaviour.
