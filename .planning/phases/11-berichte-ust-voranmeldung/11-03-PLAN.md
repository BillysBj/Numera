Produce the EÜR (Einnahmenüberschussrechnung) in the structure of the **Anlage EÜR** — Betriebseinnahmen / Betriebsausgaben on the Zufluss/Abfluss (cash) principle (success criterion 1, ACCT-07).

LOCKED decisions honored exactly:

- Kleinunternehmer book Betriebsausgaben **brutto** (no Vorsteuer line); Regelunternehmer book **netto** + separate USt lines (gate on `CompanyProfile.IsKleinunternehmer`).
- AfA / durable-asset depreciation breaks pure cash-basis — flag it explicitly out of scope for the MVP (document, do not implement).

Purpose: the freelancer/Kleinunternehmer profit report, cash-basis, tied to the ledger.
Output: `EuerCalculator` + account→EÜR-line map + report model, proven by integration tests.

Logic:
1. **Betriebseinnahmen (Zufluss):** use `RecognitionReader.ReadCashRecognitionAsync(from,to)` — income recognized at `Payment.ValueDate`. Group the recognized NET into the Betriebseinnahmen revenue lines via `EuerLineMap` (by category/rate → the mapped Zeile), and sum the recognized VAT into **Zeile 17 vereinnahmte Umsatzsteuer**. This is the SAME cash read as Ist-USt-VA, so invoice + payment postings are never double-counted (D2).
2. **Betriebsausgaben (Abfluss):** supplier payments made, net + gezahlte Vorsteuer. There is no expense/supplier-payment runtime path yet (Phase 12), so these lines resolve to 0 from real data — keep them present-but-zero (they map real accounts) and set **`IsExpenseDataIncomplete = true`** with a `Hinweis` such as "Betriebsausgaben unvollständig — Belegerfassung ab Phase 12." Do NOT fabricate expense amounts. (When a later phase supplies expense data the flag simply resolves to false.)
3. **Kleinunternehmer branch:** if `CompanyProfile.IsKleinunternehmer`, present Betriebseinnahmen without a separate USt split and Betriebsausgaben **brutto** (no Vorsteuer line). Regelunternehmer: netto revenue + Zeile-17 USt + separate gezahlte-Vorsteuer line.
4. `SummeEinnahmen`, `SummeAusgaben`, and `Gewinn = SummeEinnahmen − SummeAusgaben`.
Money `decimal` end-to-end via `RoundingPolicy`; do not truncate mid-aggregation.
