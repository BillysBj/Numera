<objective>
Build the single EN 16931 mapping layer for outbound e-invoices: `EInvoiceMapper` turns a finalized invoice's frozen `InvoicePdfModel` into ONE ZUGFeRD-csharp `InvoiceDescriptor`, and `XRechnungGenerator` saves that descriptor to XRechnung UBL and XRechnung CII byte streams. This is the "single source of truth" the phase criteria demand — the same descriptor later feeds the ZUGFeRD PDF/A-3 embed (05-04) and mirrors the inbound parser (05-05).

Purpose: Delivers the core of EINV-01 (generate XRechnung UBL+CII) and structurally guarantees EINV-02 (PDF values == XML values) by having ONE mapping path, not two. Pure model→bytes with zero DB/HTTP dependencies so it is fully unit-testable via golden files.
Output: `EInvoiceMapper`, `XRechnungGenerator`, `EInvoiceFormat` enum, the `ZUGFeRD-csharp` package on the Sales module, and golden-file tests covering every VAT category.
</objective>
