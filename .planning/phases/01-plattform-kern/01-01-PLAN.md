  <name>Task 2: Platform tenancy + DbContext base with corrected interceptor</name>
  <files>src/platform/Numera.Platform.Tenancy/Numera.Platform.Tenancy.csproj, src/platform/Numera.Platform.Tenancy/ICurrentTenant.cs, src/platform/Numera.Platform.Tenancy/TenantContext.cs, src/platform/Numera.Platform.Tenancy/TenantConnectionInterceptor.cs, src/platform/Numera.Platform.Db/Numera.Platform.Db.csproj, src/platform/Numera.Platform.Db/NumeraDbContext.cs, src/platform/Numera.Platform.Db/ITenantEntity.cs, src/platform/Numera.Platform.Db/DesignTimeDbContextFactory.cs</files>
  <action>
Add packages to Numera.Platform.Db: `Npgsql.EntityFrameworkCore.PostgreSQL --version 10.*`.

`Numera.Platform.Tenancy`:
- `ICurrentTenant` — exposes `Guid? TenantId { get; }` and `void SetTenant(Guid tenantId)`.
- `TenantContext` — scoped implementation holding the current tenant id (set by middleware in plan 01-05; usable directly in tests now).
- `TenantConnectionInterceptor : DbConnectionInterceptor` — override `ConnectionOpenedAsync` to run `SELECT set_config('app.current_tenant', @tenant, false)` via a **parameterized** DbCommand (never string interpolation), only when `tenant.TenantId` is non-null. Override `ConnectionClosing` (and async variant) to execute `RESET app.current_tenant` so pooled connections do not leak stale tenant context. This is the injection- and pool-safe correction of the bytefish blog sample — reference RESEARCH.md Pattern 1 verbatim.

`Numera.Platform.Db`:
- `ITenantEntity` — marker interface with `Guid TenantId { get; }`.
- `NumeraDbContext : DbContext` — constructor takes `ICurrentTenant`; register `TenantConnectionInterceptor` via `AddInterceptors` in `OnConfiguring` (or accept it via DI). Apply a global query filter for any `ITenantEntity` (`e => e.TenantId == currentTenant.TenantId`) as defence-in-depth. Configure `Guid` PKs to use `Guid.CreateVersion7()` default value generation where applicable (maps to PG18 uuidv7).
- `DesignTimeDbContextFactory` — `IDesignTimeDbContextFactory<NumeraDbContext>` so `dotnet ef` can create migrations at design time (uses a no-op ICurrentTenant).

Add project references: Api and Worker → Platform.Db → Platform.Tenancy.
  </action>
  <verify>`dotnet build -c Release`; confirm TenantConnectionInterceptor uses a parameter (grep for `set_config` and a `CreateParameter`/`@tenant`), and that no `$"SET ...{` string interpolation exists.</verify>
  <done>NumeraDbContext registers the interceptor and applies ITenantEntity global filter; interceptor is parameterized and RESETs on close; design-time factory present.</done>
</task>
