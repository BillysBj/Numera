<objective>
Convert the platform data layer to EF Core 10 **named** query filters and introduce the `IArchivable` soft-delete marker — the foundation every Phase-2 table depends on.

Purpose: The current `NumeraDbContext.ApplyTenantQueryFilters` uses the **unnamed** `HasQueryFilter`. Adding a second unnamed filter (for "hide archived") would silently OVERWRITE the tenant filter — a data-leak-class bug (RESEARCH.md Pattern 1 / Pitfall). Named filters compose and can be disabled individually. This plan makes tenancy AND archive coexist correctly before any archivable entity exists.

Output: `IArchivable` marker + a `NumeraDbContext` that applies a named `"Tenant"` filter to every `ITenantEntity` and a named `"NotArchived"` filter to every `IArchivable` entity.
</objective>
